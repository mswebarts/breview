== Description ==

**Breview brings the review experience of major marketplaces to your WooCommerce store.** Customers leave product reviews right from the completed order page, so every review comes from a real, verified buyer — increasing trust, social proof, and sales.

Traditionally, big e-commerce sites let customers order, receive the product, and then review it directly from their order. The default WooCommerce review system doesn't work this way — it's really just a comment form with a rating attached. Breview remasters that workflow the way it should work on every WooCommerce store.

**Why store owners choose Breview:**

* **Verified buyers only** — only customers who actually purchased and completed an order can review, and only once per purchase.
* **Higher review volume** — automatic email reminders prompt customers to review after their order completes.
* **Better on-page conversion** — reviews display on product pages with fast Ajax loading and pagination.
* **Works with your theme** — styling adapts automatically, no configuration required.
* **Multi-vendor ready** — full Dokan marketplace compatibility.

== Installation ==

This section describes how to install the plugin and get it working.

**Method One – WordPress Admin (recommended)**

1. Download the plugin zip file.
2. Go to your WordPress admin dashboard -> Plugins -> Add New.
3. Click the "Upload Plugin" button.
4. Upload the downloaded plugin zip file.
5. Click "Activate".

Once activated, go to MS Web Arts -> Breview from the admin menu to control all plugin settings.

**Pro Tip:** If you see any PHP warning on your site's frontend, go to MS Web Arts -> Breview and click the Save Settings button.

**Method Two – FTP / File Manager**

1. Download the plugin zip file.
2. Connect to your hosting via FTP or your host's File Manager.
3. Navigate to your WordPress installation directory -> wp-content -> plugins.
4. Upload the uncompressed plugin folder (if using FTP) or the zip file (if using cPanel — you must extract it after upload).
5. Go to WordPress admin dashboard -> Plugins -> Installed Plugins -> Activate Breview.

Hope the installation was as smooth as the plugin works!

== Frequently Asked Questions ==

= Does Breview replace the default WooCommerce review system? =

Breview adds a marketplace-style workflow that lets verified buyers review products from their completed order page. It complements WooCommerce by ensuring reviews come from real purchasers, and displays those reviews on your product pages.

= Does it work with any WordPress theme? =

Yes. Breview automatically adapts its styling to your active theme, so reviews look native to your store with no extra configuration.

= Is Breview compatible with multi-vendor marketplaces? =

Yes. Breview is fully compatible with the Dokan multi-vendor marketplace.

= Can customers review a product more than once? =

No. Each customer can review a purchased product only once per completed order, ensuring authentic, verified reviews.

= How do I remove PHP warnings in the review tab? =

The review tab may show a warning after you activate the plugin. Go to your WordPress admin panel -> MS Web Arts -> Breview and click the Save Settings button. This saves the settings to the database and clears the warnings.

= How can I update the plugin? =

You can update Breview using WordPress's automatic and manual update options.

= Do I need to use both the free and pro versions? =

No. If you've purchased the Pro version (1.2.0 or above), you don't need the free version. From version 1.2.0 the free and pro versions are separate, and activating Pro automatically deactivates the free version.
